# BitLearn

**Aprende poco a poco, recuerda por más tiempo.**

BitLearn es una plataforma web de microaprendizaje diseñada para aprender programación de forma sencilla, mediante lecciones cortas, actividades prácticas y repasos personalizados.

Su principal característica es el uso del algoritmo **SuperMemo-2 (SM-2)**, que ayuda a organizar los repasos según qué tan bien recuerdas lo aprendido.

## ¿Qué ofrece BitLearn?

- **Cursos interactivos:** aprende HTML, CSS y JavaScript desde sus fundamentos.
- **Lecciones breves:** estudia conceptos de programación paso a paso.
- **Preguntas prácticas:** comprueba tus conocimientos después de cada lección.
- **Tarjetas de estudio:** refuerza tu memoria mediante flashcards.
- **Repasos inteligentes:** recibe recomendaciones de cuándo volver a estudiar.
- **Seguimiento personal:** consulta tus avances, estadísticas y progreso.
- **Retención estimada:** visualiza una proyección de cuánto podrías recordar con el tiempo.

## Cursos disponibles

| HTML | CSS | JavaScript |
|---|---|---|
| Estructura de páginas web | Diseño y estilos | Lógica y programación |

## Tecnologías

BitLearn está desarrollado utilizando:

- **Vue.js** para la interfaz.
- **Node.js y Express** para el servidor.
- **PostgreSQL** para almacenar los contenidos y el progreso.

## Objetivo del proyecto

Facilitar el aprendizaje de programación web mediante sesiones cortas y repasos adaptados al rendimiento de cada estudiante.

**BitLearn — Aprende, practica y recuerda.**
